## Gaps

| Feature | Why it matters | Status | Owner |
|---|---|---|---|
| Instruction-level decode of RV32M opcodes | Env 2 drives `muldiv_op_e` directly, never the 32-bit encodings. Nothing verifies that `funct7`/`funct3` map to the right operation. | **Deferred** | M4 |
| Back-to-back operations without idle cycles | The driver inserts a gap between transactions. A pipeline will issue consecutively. | **Planned** | M3 |
| Operation abandoned mid-flight (flush) | The pipeline must be able to cancel a 35-cycle divide on a branch mispredict. No such input exists. | **Deferred** | M3 |
| `MULHSU` operand-sign cross specifically | Covered by generic operand classes, but the signed×unsigned asymmetry has no dedicated cross. | **Partial** | M3 |
